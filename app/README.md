# SEO Text Checker App

Это локальное приложение для ПК. Оно не зависит от Google Docs DOM: вы просто вставляете текст в редактор, а приложение анализирует его как статью для WordPress.

## Как открыть

Откройте файл:

```text
D:\WORK\checker_keywoard\app\index.html
```

Можно открыть двойным кликом или перетащить файл в Chrome.

## Как работать

1. Вставьте текст в левый редактор.
2. Если вставляете из WordPress, Google Docs или Word, форматирование обычно сохранится: H1, H2, H3, списки, абзацы.
3. Если вставился обычный текст без форматирования, нажмите `Распознать структуру`.
4. В Settings вставьте диапазон из Google Sheets в блок `Ключи из таблицы`.
5. Проверьте предпросмотр ключей.
6. Нажмите `Проверить`.

Удобный вариант: выделите в таблице только строки с ключами, даже без шапки, скопируйте и вставьте в приложение. Оно само определит:

- Page;
- Keywords;
- Volume;
- Комментарии;
- Объем текста СБП;
- Вхождения ключей.

Если вставляете вместе с шапкой, оно тоже сработает. Если приложение ошиблось, откройте `Маппинг колонок` и выберите нужные колонки вручную.

Ручной формат через `|` остался как запасной вариант:

```text
keyword | min | max | type | comment
```

## Что приложение понимает

- `H1`, `H2`, `H3`, `H4`;
- абзацы;
- маркированные списки;
- нумерованные списки;
- длинные абзацы;
- слишком длинные заголовки;
- несколько H1;
- отсутствие H1;
- нарушение иерархии заголовков;
- основной ключ в H1;
- основной ключ в первом абзаце.

## Как помочь распознаванию plain text

Если текст без HTML, можно явно пометить заголовки:

```text
H1: Vegastars Casino Review
H2: What Makes Vegastars Casino Special
H3: Pros
- Large pokies library
- Mobile-friendly layout
H3: Cons
- Terms should be checked
```

Также приложение само пытается угадать короткие строки как заголовки, вопросы как H2, а строки с `-`, `*`, `•`, `1.` как списки.

## Копирование в WordPress

На вкладке Structure есть кнопка `Скопировать HTML для WP`. Она копирует чистую HTML-структуру из редактора: headings, paragraphs, lists.

## Чем это лучше расширения

Расширение зависит от того, как Google Docs отдает текст в DOM. Локальное приложение контролирует свой редактор само, поэтому стабильнее считает структуру, ключи и объем.
