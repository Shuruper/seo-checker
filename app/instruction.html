Инструкция к локальному SEO-редактору

Что делает эта программа?

Это инструмент для профессиональной проверки SEO-текстов. Программа полностью работает в вашем браузере, мгновенно подсвечивает ключи из ТЗ (технического задания) и вычисляет переспам. Программа создана для того, чтобы убрать рутину при вписывании сложных ключей и проверке готовых текстов от копирайтеров.

  • Распознавание структуры: Автоматически конвертирует заголовки (##, ###), таблицы (| Код | Значение |) и списки в чистый HTML-стандарт для CMS (например, WordPress). Спецсимволы Markdown аккуратно удаляются.
  • Строгий подсчет (Strict Exact Match): Считает вхождения так, как они есть. Если у вас прописан ключ "vegastars", а в тексте есть "vegastars casino", счетчик не будет засчитывать короткое слово как независимое. Это исключает искусственный переспам!
  • Проверка чужой семантики ("Каннибализация"): Позволяет загрузить все ключи проекта. Редактор предупредит, если автор вписал в эту статью ключи, предназначенные для соседней страницы ресурса.

Как вставлять ключи (Таблица ТЗ)

Идеальный формат работы программыстроен на Google Таблицах (Шитах). Если ваше SEO ТЗ сделано в таблице, вам больше не нужно ничего выписывать руками.

  1. В Google Sheets выделите прямоугольную область ключей — можно прямо с шапкой (Keyword, Volume, Объем текста, Вхождения).
  2. Нажмите Ctrl + C.
  3. Перейдите во вкладку Настройки в программе и вставьте (Ctrl + V) в поле "Ключи из таблицы".

Супер-фишка: Программа сама угадает, где у вас объем текста (например, ~15000), где частотность, а где количество вхождений. Просто вставьте таблицу, и приложение автоматически все пересчитает и заполнит!

Настройки

  • Режим подсчета (Strict Exact Match): Ключ считается найденным, только если он не является частью более длинного запрашиваемого ключа.
  • Independent Exact Match: Независимый подсчет: длинные и короткие ключи считаются одновременно.
  • Режим регистра (Учитывать / Не учитывать): При строгом регистре Apple и apple будут разными ключами.

Local SEO Editor Instructions

What does this program do?

This is an internal tool for professional SEO content auditing. It runs entirely locally in your browser, instantly highlighting technical requirements (keywords) and calculating overuse (spam density). It removes the manual hassle of matching complex keywords and validating copywriter texts.

  • Structure Parsing: It automatically converts Markdown-like headings (##, ###), tables (| Col | Val |) and lists into raw standard HTML elements perfect for WordPress pasting. All dashes and hashes are cleaned.
  • Strict Exact Match Mode: Follows a "longest match wins" logic. If you search for "vegastars" and "vegastars casino", finding the latter will NOT falsely inflate the count of "vegastars". Prevents overlap spam warnings!
  • Global Semantic Tracking: Paste the full project keyword tree into the "All Semantics" tab. If the author accidentally uses a keyword meant for a completely different page, it highlights as a "Foreign Key" error.

How to paste Keywords (Spreadsheet format)

The program is natively built to understand Google Spreadsheets and Excel.

  1. Open your Google Sheet and select the block containing your SEO target — you can include the headers or exclude them, it doesn't matter.
  2. Press Ctrl + C.
  3. Go to the Settings tab in the app and press Ctrl + V in the "Keywords from Spreadsheet" field.

Magic Auto-Detect: The app will automatically figure out which column is the Target Text Volume (e.g. ~15000), Search Volume, and Required Occurrences. Just paste the matrix, and the app recalculates everything instantly!

App Settings

  • Counting Mode (Strict Exact Match): Core mode. A key is counted only if it stands alone. If it sits inside a longer tracked key, it stays grouped.
  • Independent Exact Match: Fallback mode where overlap boundaries are disabled and every key counts simultaneously.
  • Case Sensitivity: Treats Apple and apple as completely independent exact phrase queries when activated.
