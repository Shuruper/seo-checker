# План разработки

## Этап 1. MVP

Готово в текущем каркасе:

1. Chrome Extension Manifest V3.
2. Работа на странице Google Docs.
3. Ручной ввод ключей.
4. Подсчет вхождений.
5. Таблица `Keyword / Required / Found / Status / Density`.
6. Символы с пробелами, СБП, слова.
7. Временная подсветка найденных ключей.
8. Отдельные статусы для отсутствующих и переспамленных ключей.
9. CSV-отчет через копирование в буфер или download permission.

Что стоит усилить внутри MVP:

1. Добавить permission `downloads`, если нужен прямой файл CSV.
2. Добавить unit-тесты для `analyzer.js`.
3. Перенести popup в side panel.
4. Добавить цветовую подсветку по статусам.
5. Улучшить чтение полного текста Google Docs.

## Этап 2. Google Sheets и структура

1. Добавить OAuth через `chrome.identity`.
2. Подключить Google Sheets API.
3. Реализовать чтение таблицы по ссылке.
4. Сделать экран маппинга колонок.
5. Сохранять проекты в `chrome.storage.local`.
6. Автоматически выбирать страницу:
   - по названию Google Docs;
   - по Page из таблицы;
   - с ручным fallback-выбором.
7. Реализовать модель заголовков H1-H4.
8. Сравнивать фактическую и ожидаемую структуру.
9. Добавить вкладку Headings.
10. Расширить Issues:
    - primary keyword missing in H1;
    - primary keyword missing in first paragraph;
    - missing FAQ keywords;
    - heading hierarchy issues.

## Этап 3. Расширенный анализ

1. Word Online connector.
2. Broad match с нормальной токенизацией.
3. Лемматизация для английского/русского при необходимости.
4. Экспорт отчета в Google Sheets.
5. История проверок.
6. Сравнение двух наборов ключей.
7. Проверка пересечений интентов.
8. Проверка длинных абзацев.
9. Проверка длинных H2/H3.
10. Ignore-режим для ключей.

## Этап 4. Командная версия

1. Backend на Node.js.
2. Общие проекты команды.
3. Роли и доступы.
4. Централизованные шаблоны маппинга таблиц.
5. Хранение истории проверок.
6. Сравнение версий документа.
7. Экспорт в BI/Looker Studio при необходимости.

## Рекомендуемый стек для production

- Chrome Extension Manifest V3.
- React + Vite + TypeScript.
- Side Panel API для основного интерфейса.
- Content scripts для live-навигации и подсветки.
- Google APIs:
  - Sheets API для ТЗ;
  - Docs API для полного текста и структуры документа.
- `chrome.storage.local` для MVP и персональных проектов.
- Node.js backend только когда появятся командная работа, история, общий доступ и серверный экспорт.
