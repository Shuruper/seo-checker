# Ограничения Google Docs и обходы

## 1. Не весь текст есть в DOM

Google Docs использует виртуализированный редактор. В больших документах часть страниц может не находиться в DOM, пока пользователь до них не проскроллил.

Обход:

- для точного анализа использовать Google Docs API;
- DOM использовать для подсветки и переходов в видимой части;
- показывать пользователю источник текста: `DOM` или `Docs API`.

## 2. Подсветка может быть нестабильной

Внутренняя структура Google Docs меняется. Прямая обертка слов в `<span>` может ломать редактор или мешать вводу.

Обход:

- использовать CSS Highlight API или overlay;
- не изменять текстовые узлы документа;
- хранить подсветку только как временное состояние браузера;
- давать кнопку `Снять подсветку`.

## 3. DOM-заголовки не всегда надежны

В Google Docs заголовок может выглядеть как H2, но в DOM не быть `<h2>`.

Обход:

- получать structure через Google Docs API;
- читать paragraphStyle.namedStyleType:
  - `HEADING_1`;
  - `HEADING_2`;
  - `HEADING_3`;
  - `HEADING_4`.

## 4. OAuth нужен для полного текста

Если документ приватный, расширение не сможет прочитать его через Google Docs API без OAuth и разрешения пользователя.

Обход:

- для MVP оставить DOM-режим без OAuth;
- для версии 2 добавить `chrome.identity`;
- запрашивать минимальные scopes:
  - `https://www.googleapis.com/auth/documents.readonly`;
  - `https://www.googleapis.com/auth/spreadsheets.readonly`.

## 5. Google Sheets имеют разную структуру

Колонки в ТЗ могут называться по-разному: `Keywords`, `Keyword`, `Вхождения ключей`, `Required`, `Volume`, `Объем текста СБП`.

Обход:

- делать экран маппинга колонок;
- пытаться автодетектить колонки по похожим названиям;
- сохранять маппинг на уровне проекта;
- давать предпросмотр первых 10 строк.

## 6. Exact match и склонения

Точное совпадение хорошо для английских SEO-ключей, но плохо для языков со склонениями.

Обход:

- MVP: exact match и broad match;
- версия 3: лемматизация;
- для русского/украинского лучше подключать backend или WASM-библиотеку, если нужна высокая точность.

## 7. Word Online

Word Online имеет другой DOM и может требовать Microsoft Graph API для надежного чтения документа.

Обход:

- вынести connector в отдельный модуль;
- начинать с DOM-текста видимого документа;
- затем добавить Microsoft Graph для полного текста, если продукт реально требует Word Online.
